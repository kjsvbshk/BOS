# Glosario del negocio

Términos tal como los usa el cliente (reunión del 2026-11-18). Entre paréntesis,
el minuto de la transcripción donde aparecen.

| Término | Significado |
|---|---|
| **Compraventa** | El negocio: compra artículos con pacto de retroventa (empeño). |
| **Contrato / empeño** | Registro de un préstamo garantizado con un artículo. Tiene número, cliente, capital, plazo, porcentaje y fecha (01:38). |
| **Retroventa** | Modalidad del contrato: el cliente «vende» el artículo y luego lo vuelve a comprar (15:02). |
| **Contrato común** | Contrato habitual con artículos (oro, relojes, bicicletas…). El número lo digita el usuario desde su libreta física (02:05, 22:51). |
| **Contrato no común / hipotecario** | Préstamos sobre casas, vehículos u otros. El sistema asigna el número consecutivo; no se puede cambiar (02:33, 22:51). Casi no se usa (20:46). |
| **Capital** | Valor prestado al cliente (06:33). |
| **Plazo** | Meses pactados: 1, 2, 3 o 6. Por defecto 6 (02:50). |
| **Porcentaje** | Interés mensual sobre el capital. Por defecto 10 % (02:50). |
| **Intereses / sobrecosto** | Lo que se cobra por mes sobre el capital. En los informes del sistema anterior aparece como «sobrecosto» (21:03, 38:51, 45:48). |
| **Prórroga** | Pago anticipado de uno o varios meses de intereses para mantener vigente el contrato (16:33). |
| **Abono (a capital)** | Pago parcial que reduce el capital del contrato; se registra modificando el contrato (13:41, 30:35). |
| **Retiro** | El cliente paga capital más intereses pendientes y recupera su artículo. El contrato queda «retirado» (14:50). |
| **Valor de retiro** | Capital más intereses pendientes a una fecha (11:00). |
| **Vigente** | Contrato activo dentro de su plazo. |
| **Vencido** | Contrato que superó su plazo sin retirarse (18:25). |
| **Pasar a propios / traslado** | El dueño decide que un contrato vencido pasa a ser mercancía de la compraventa. Deja de aparecer en contratos vigentes (23:56). |
| **Mercancía propia / propios** | Artículos que ya pertenecen a la compraventa (24:21). |
| **Salida de inventario** | Venta o separado de un artículo propio (25:28). |
| **Separado** | Venta a plazos: se fija un valor, una fecha estimada de entrega y se reciben abonos (28:01). |
| **Código de mercancía** | Categoría del artículo (oro, reloj, cámara, bicicleta…), consultable con F1 (07:09). |
| **Artículo esporádico** | Código para artículos que nunca se habían empeñado; se describe a mano (07:35). |
| **Inventario general (código 0)** | En los filtros, «0» significa todos los códigos (20:09). |
| **Quilataje / calidad de oro** | 8, 10, 14, 16, 18, 24 quilates. Consultable con F1 (08:42, 43:51). |
| **Número de movimiento** | Identificador de cada operación (ingreso, interés, retiro, venta, abono). Permite anularla (32:16). |
| **Ingresos / egresos de caja** | Gastos, utilidades, pérdidas y otros movimientos de dinero, clasificados por código (28:47). |
| **Código de gasto** | Concepto configurable: 28 sueldos, 33 seguridad social, 42 cafetería… (36:24–37:21). |
| **Utilidad ocasional** | Ganancia de una compra y venta inmediata que no pasó por el inventario (29:05). |
| **Pérdida (ajuste)** | Registro para cuadrar la caja del sistema con la caja real (29:32). |
| **Auditor interno** | Informe de modificaciones y anulaciones con su usuario (51:08). |
